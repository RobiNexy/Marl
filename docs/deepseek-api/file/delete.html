删除文件

DELETE 
https://api.deepseek.com/files/:file_id

删除一个文件。

Request​

Path Parameters
    file_id stringrequired

    要删除的文件 ID。

Responses​

  • 200

OK, 返回删除状态。

Schema
    id stringrequired

    被删除文件的 ID。

    object stringrequired

    deleted booleanrequired
